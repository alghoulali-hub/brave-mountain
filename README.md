# Brave Mountain

A reward app for Taym: brave steps up a mountain, a Calm Corner, healthy-food missions, and prizes.

- App: https://alghoulali-hub.github.io/brave-mountain/
- Data lives in Supabase (project `taym-brave-app`). `config.js` holds only the public connection values.
- `supabase/setup.sql` recreates the database on a new, empty Supabase project.
